Account Settings Unsaved Guard

A settings form prevents accidental tab changes when the active panel contains unsaved field edits.

Scenario

A user edits profile or notification settings and needs a clear chance to save or discard changes before leaving the panel.

Try it

  • Edit a field in the active tab.
  • Try to activate another tab and choose Cancel in the confirmation.
  • Save or reset the form, then switch tabs again.

Accessibility notes

  • The guard uses the cancellable a11y-tabs:before-change event.
  • Form controls have visible labels and remain normal native controls.
  • Dirty panels receive a data attribute for non-color styling.
  • The demo uses native confirmation; production apps may provide an accessible custom modal.

Developer notes

  • Imports: A11yTabsUnsavedGuard from the built add-on module.
  • Options used: a custom message and default field selector.
  • Methods used: isDirty() and markClean().
  • The guard tracks inputs, textareas, and selects inside tab panels.

Mark a panel clean only after its save or reset operation succeeds. The add-on can cancel a tab change, but your application remains responsible for an accessible confirmation UI and any asynchronous persistence errors.

How it works

Form fields stay in ordinary tab panels. The guard tracks edits and cancels a pending tab change until the user confirms or the application marks the saved panel clean.

HTML

<div data-a11y-tabs>
  <div data-a11y-tabs-list aria-label="Profile settings">
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="account">
      Account
    </button>
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="privacy">
      Privacy
    </button>
  </div>
  <section id="account" data-a11y-tabs-panel>
    <label>Display name <input name="displayName"></label>
  </section>
  <section id="privacy" data-a11y-tabs-panel hidden>...</section>
</div>

JavaScript

import { createTabs } from "../../dist/index.js";
import { A11yTabsUnsavedGuard } from "../../dist/addons/a11y-tabs-unsaved-guard.js";

const root = document.querySelector("[data-a11y-tabs]");
const form = document.querySelector("form");

if (root instanceof HTMLElement && form instanceof HTMLFormElement) {
  const tabs = createTabs(root);
  const guard = new A11yTabsUnsavedGuard(tabs);

  form.addEventListener("submit", () => guard.markClean(tabs.getActivePanel()));
}
