Campaign Tab Analytics Log

A product team records tab changes as normalized data without adding any analytics SDK to the component package.

Scenario

A dashboard owner wants to understand which campaign tab users inspect while keeping tracking code outside the core tabs behavior.

Try it

  • Activate different campaign tabs.
  • Watch the event log update with tab id, panel id, and indexes.
  • Use keyboard navigation to confirm changes are logged the same way.

    Accessibility notes

    • The add-on listens to the same bubbling change event that keyboard and pointer activation use.
    • The log uses an ordered list with polite updates so changes are available to assistive technology.
    • No user-identifying data is collected in this demo.
    • The add-on does not change tab semantics, focus, or keyboard behavior.

    Developer notes

    • Imports: createTabs and A11yTabsAnalytics from built ESM files.
    • Root selector: [data-a11y-tabs] plus data-analytics-id for a stable log id.
    • Options used: onChange(data, event) receives normalized tab data.
    • Forward the callback data to your own analytics layer if needed.

    The add-on normalizes tab-change context but does not send or store it. Your integration must decide which events are appropriate to collect, apply consent rules, and forward only the data your analytics service needs.

    How it works

    A stable analytics id lives on the tabs root. The add-on receives normalized change data and passes it to the callback; this demo writes that data to a local event log.

    HTML

    <div data-a11y-tabs data-analytics-id="campaign-tabs">
  <div data-a11y-tabs-list aria-label="Campaign performance">
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="overview">
      Overview
    </button>
  </div>
  <section id="overview" data-a11y-tabs-panel>...</section>
</div>
<ol id="snippet-analytics-log" aria-live="polite"></ol>

    JavaScript

    import { createTabs } from "../../dist/index.js";
import { A11yTabsAnalytics } from "../../dist/addons/a11y-tabs-analytics.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  const tabs = createTabs(root);
  new A11yTabsAnalytics(tabs, (data) => {
    console.log(data.rootId, data.tabText, data.panelId);
  });
}
