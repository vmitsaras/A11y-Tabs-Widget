Review Queue Badges

A moderation console shows counts and status on tabs while keeping accessible tab names deliberate and readable.

Scenario

Reviewers need a compact view of waiting work, urgent issues, and completed items without relying on color alone.

Try it

  • Add and clear review counts.
  • Toggle the urgent issue badge.
  • Move between tabs and listen for the updated accessible names.

Example

Reviews

Items waiting for editorial review before they can be published.

Urgent

Reports that need same-day action from a moderator.

Done

Completed reviews are quiet by default when their count is zero.

Badges initialized.

Accessibility notes

  • Visual badge text is hidden from the accessible name by default.
  • The add-on supplies intentional aria-label text for each badge state.
  • Counts are also announced in the page status message after demo actions.
  • Zero counts are hidden to keep quiet tabs visually clean.

Developer notes

  • Imports: A11yTabsBadges from the built add-on module.
  • Badge keys can be panel ids or tab ids.
  • Options used: formatAccessibleLabel to control screen-reader names.
  • Instance methods used: updateCount() and setBadge().

Badge text is presentation data, not a replacement for the tab label. Provide a concise accessible label for every meaningful badge state and clear stale counts when the underlying review queue changes.

How it works

Badge data is keyed by panel id. The add-on renders the visual badge, creates an intentional accessible label, and exposes methods for updating counts when application data changes.

HTML

<div data-a11y-tabs>
  <div data-a11y-tabs-list aria-label="Moderation queues">
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="reviews">
      Reviews
    </button>
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="urgent">
      Urgent
    </button>
  </div>
  <section id="reviews" data-a11y-tabs-panel>...</section>
  <section id="urgent" data-a11y-tabs-panel hidden>...</section>
</div>

JavaScript

import { createTabs } from "../../dist/index.js";
import { A11yTabsBadges } from "../../dist/addons/a11y-tabs-badges.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  const tabs = createTabs(root);
  const badges = new A11yTabsBadges(tabs, {
    reviews: { count: 4, variant: "info", label: "items waiting" },
    urgent: { count: 1, variant: "error", label: "urgent reports" }
  });

  badges.updateCount("reviews", 5);
}
