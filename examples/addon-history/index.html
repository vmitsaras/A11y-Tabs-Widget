Developer Docs Lab

Deep-Linkable Release Notes

A documentation page records each tab activation in browser history so Back and Forward return to previously viewed sections.

Scenario

A developer opens release notes, jumps between versions, and expects the URL hash plus browser navigation to preserve context.

Try it

  • Activate two or three version tabs.
  • Watch the URL hash and status text update.
  • Use the browser Back and Forward buttons to restore panels.

Accessibility notes

  • Back and Forward restore the selected tab without changing the core keyboard model.
  • The active panel remains exposed through normal tabs semantics.
  • The status line announces URL-state changes for this demo.
  • Hash mode is best for real sections users may share directly.

Developer notes

  • Imports: A11yTabsHistory from ../../dist/addons/a11y-tabs-history.js.
  • Options used: mode: "hash" and pushInitialState: true.
  • Each panel needs a stable id for URL restoration.
  • The add-on listens for popstate and the core a11y-tabs:change event.

Hash history treats panel IDs as public links. Preserve those IDs after release, and use this mode only when each tab represents a destination that is useful to bookmark, share, and restore with browser navigation.

How it works

The panel ids become URL state. The history add-on records tab changes and restores the matching tab when users navigate Back or Forward.

HTML

<div data-a11y-tabs>
  <div data-a11y-tabs-list aria-label="Release notes">
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="v010">
      0.1.0
    </button>
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="v020">
      0.2.0
    </button>
  </div>
  <section id="v010" data-a11y-tabs-panel>...</section>
  <section id="v020" data-a11y-tabs-panel hidden>...</section>
</div>

JavaScript

import { createTabs } from "../../dist/index.js";
import { A11yTabsHistory } from "../../dist/addons/a11y-tabs-history.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  const tabs = createTabs(root);
  new A11yTabsHistory(tabs, { mode: "hash" });
}
