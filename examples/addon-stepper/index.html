E-commerce Flow

Checkout Progress Stepper

A checkout flow mirrors the active tab into external progress text and Previous/Next buttons.

Scenario

A shopper needs clear progress through a four-step checkout, including disabled navigation at the start and end.

Try it

  • Use the external Next and Previous controls.
  • Use Arrow keys in the tablist and watch progress stay in sync.
  • Confirm Previous is disabled on step one and Next on the final step.

Example

Step of

Account

Sign in or continue as a guest.

Shipping

Choose a delivery address and shipping speed.

Payment

Enter card details using labeled fields in your application.

Review

Confirm the order before placing it.

Accessibility notes

  • Progress text uses a polite live region for step changes.
  • External controls are real buttons and become disabled at the ends.
  • The tablist remains the source of truth for selected state and roving focus.
  • Focus stays on whichever control the user activated.

Developer notes

  • Imports: A11yTabsStepper from the built add-on module.
  • Stepper root selector: [data-a11y-tabs-stepper].
  • Child selectors: current, total, completed, previous, and next data attributes.
  • Options used: custom formatCompleted text.

The add-on mirrors the active tab into progress text and external controls; it does not validate a step or prevent direct tab activation. Add those product rules separately when later steps depend on earlier input.

How it works

The add-on uses the existing tab order as a sequence. It inserts Previous and Next controls, keeps progress text synchronized, and activates panels through the core tabs instance.

HTML

<div data-a11y-tabs>
  <div data-a11y-tabs-list aria-label="Application steps">
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="profile">
      Profile
    </button>
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="review">
      Review
    </button>
  </div>
  <section id="profile" data-a11y-tabs-panel>...</section>
  <section id="review" data-a11y-tabs-panel hidden>...</section>
</div>

JavaScript

import { createTabs } from "../../dist/index.js";
import { A11yTabsStepper } from "../../dist/addons/a11y-tabs-stepper.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  const tabs = createTabs(root);
  new A11yTabsStepper(tabs);
}
