Checkout Validation Summary

A checkout form marks tabs that contain invalid fields, adds badges, and focuses the first problem when the user validates the form.

Scenario

A shopper submits a multi-panel checkout form and needs to know which tab contains the first field that requires attention.

Try it

  • Leave the form as-is and press Validate checkout.
  • Notice invalid tabs receive badges and descriptions.
  • Fill the fields, then validate again.
  • Use Reset form to return to the error state.

Accessibility notes

  • Fields use native labels and validation constraints.
  • Invalid tabs receive a badge and an accessible description.
  • The status region reports the total number of invalid fields.
  • focusFirstInvalid() activates the correct tab and focuses the first invalid control.

Developer notes

  • Imports: A11yTabsValidation from the built add-on module.
  • Options used: custom describe text and card-number validation.
  • Methods used: update(), hasInvalid(), and focusFirstInvalid().
  • Use novalidate only when you provide a deliberate validation flow like this demo.

Native constraints and your custom validators remain the source of truth. Call update() after validity changes, then use focusFirstInvalid() only in response to a deliberate validation action.

How it works

Native form constraints remain the source of truth. The validation add-on summarizes invalid fields by panel, marks affected tabs, and activates the right panel before focusing the first invalid field.

HTML

<form id="checkout" novalidate>
  <div data-a11y-tabs>
    <div data-a11y-tabs-list aria-label="Checkout sections">
      <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="contact">
        Contact
      </button>
    </div>
    <section id="contact" data-a11y-tabs-panel>
      <label>Email <input type="email" required></label>
    </section>
  </div>
  <button type="submit">Validate checkout</button>
</form>

JavaScript

import { createTabs } from "../../dist/index.js";
import { A11yTabsValidation } from "../../dist/addons/a11y-tabs-validation.js";

const root = document.querySelector("[data-a11y-tabs]");
const form = document.getElementById("checkout");

if (root instanceof HTMLElement && form instanceof HTMLFormElement) {
  const validation = new A11yTabsValidation(createTabs(root));

  form.addEventListener("submit", (event) => {
    event.preventDefault();
    validation.update();
    validation.focusFirstInvalid();
  });
}
