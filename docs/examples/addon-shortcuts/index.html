Keyboard Lab

Direct Jump Shortcuts

A power-user workspace adds optional shortcuts for direct tab activation while preserving the normal tabs keyboard pattern.

Scenario

Support agents need to jump quickly between inbox, queue, notes, and audit panels without removing Arrow key navigation.

Try it

  • Tab to the active Inbox tab, then press Ctrl+1, Ctrl+2, Ctrl+3, or Ctrl+4.
  • The demo uses Ctrl instead of Option so macOS keyboard layouts do not turn number keys into symbols.
  • Use Arrow keys in the tablist to confirm the core behavior remains.
  • Tab into the notes field and confirm shortcuts are ignored while editing.

Accessibility notes

  • Shortcuts are optional and documented on screen.
  • The demo keeps standard tablist Arrow, Home, End, Enter, and Space behavior.
  • Editable controls are ignored so text entry is not interrupted.
  • Shortcuts stop when focus leaves the tabs widget; document-wide shortcuts require an explicit opt-in.
  • A successful shortcut moves focus to the activated tab so focus is not left in a panel that becomes hidden.
  • Browser, operating system, and assistive technology commands can still reserve key combinations.

Developer notes

  • Imports: A11yTabsShortcuts from the built add-on module.
  • Options used: explicit shortcut mappings, the default scope: "root", and ignoreEditable: true.
  • Shortcut targets can be indexes, tab ids, panel ids, or callbacks.
  • This demo uses Ctrl-number shortcuts because macOS Option-number combinations can report symbols instead of digit keys.
  • Per-tab shortcut attributes are not read automatically; map them into the shortcuts option when you want shortcut labels next to tab markup.
  • Open DevTools to inspect [a11y-tabs-shortcuts debug] logs for each keydown event.
  • Use global scope only when the application intentionally owns those shortcuts.
  • Disabled, hidden, disconnected, missing, or panel-less targets are not activated and emit a11y-tabs:shortcut-unavailable.
const shortcuts = Array.from(
  root.querySelectorAll("[data-a11y-tabs-tab]")
)
  .map((tab, index) => {
    const combo = tab.getAttribute("data-a11y-tabs-shortcut");
    return combo ? { combo, target: index } : null;
  })
  .filter(Boolean);

new A11yTabsShortcuts(tabs, { shortcuts });

Shortcut mappings are an optional acceleration layer. Document every active combination near the widget, avoid browser and assistive-technology conflicts, and retain the complete Arrow, Home, End, Enter, and Space flow.

How it works

Shortcut declarations map key combinations to panel ids. The add-on listens within the tabs root, ignores editable controls, and moves focus to the activated tab after a successful shortcut.

HTML

<div data-a11y-tabs>
  <div data-a11y-tabs-list aria-label="Editor sections">
    <button
      type="button"
      data-a11y-tabs-tab
      data-a11y-tabs-panel-id="preview"
      data-tab-shortcut="Alt+1"
    >
      Preview
    </button>
  </div>
  <section id="preview" data-a11y-tabs-panel>...</section>
</div>

JavaScript

import { createTabs } from "../../assets/index.js";
import { A11yTabsShortcuts } from "../../assets/addons/a11y-tabs-shortcuts.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  const tabs = createTabs(root);
  new A11yTabsShortcuts(tabs);
}
