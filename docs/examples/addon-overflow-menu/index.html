Release channel tabs with an overflow shortcut

Compare nine release channels in the original scrollable tablist, then use a generated menu to jump directly when every tab cannot fit.

Scenario

A release dashboard needs to keep familiar tabs available while giving people a faster way to reach channels that are currently out of view.

Working example

Start with the narrow preview to see overflow. The generated menu mirrors every tab, including the current and unavailable channels.

Try it

  1. Leave the preview on Narrow and open Browse all channels.
  2. Choose Security and confirm its original tab scrolls into view and its release details appear.
  3. In the original tablist, use Arrow keys or Home/End, then press Enter or Space to select.
  4. Open the generated menu again, then press Escape and confirm focus returns to its trigger.
  5. At a wide desktop viewport, choose Wide and confirm the menu hides when every tab fits.

Accessibility notes

  • The original tablist remains visible and keyboard-operable.
  • The generated menu button is a real button with aria-haspopup and aria-expanded.
  • The menu mirrors every tab, marks the selected item, and exposes Retired as unavailable.
  • Choosing a menu item selects and focuses its original tab; Escape closes the menu and returns focus to the trigger.
  • The width state is announced politely, while tab selection uses the existing focus and ARIA tabs state without a duplicate live announcement.

Developer notes

  • Imports: A11yTabsOverflowMenu from the built add-on module.
  • Options used: control: "menu", the label “All release channels,” and the button text “Browse all channels.”
  • The add-on sets data-a11y-tabs-overflow on the root.
  • The Narrow/Wide buttons change only the demo container; the add-on still measures the real tablist.

The generated menu supplements the tablist instead of replacing it. It lists every channel rather than only the currently clipped labels, so selected and disabled state remain consistent in both controls.

How it works

The tabs remain horizontally scrollable. When labels overflow, the add-on creates a jump menu that activates the same tabs without replacing their native keyboard behavior.

HTML

<div data-a11y-tabs>
  <div data-a11y-tabs-list aria-label="Workspace sections">
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="overview">
      Overview
    </button>
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="activity">
      Recent activity
    </button>
  </div>
  <section id="overview" data-a11y-tabs-panel>...</section>
  <section id="activity" data-a11y-tabs-panel hidden>...</section>
</div>

JavaScript

import { createTabs } from "../../assets/index.js";
import { A11yTabsOverflowMenu } from "../../assets/addons/a11y-tabs-overflow-menu.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  const tabs = createTabs(root);
  new A11yTabsOverflowMenu(tabs);
}
