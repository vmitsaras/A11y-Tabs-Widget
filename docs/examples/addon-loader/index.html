Lazy Loaded Incident Briefs

A dashboard loads tab panel content only when users open a report, including a local error state and retry path.

Scenario

An operations team keeps the page fast by loading heavy report text on demand while exposing loading and error messages.

Try it

  • Open each report tab and wait for the live loading message.
  • Open the Risk tab to see an error state with a retry button.
  • Use Fix endpoint, then retry the Risk tab.
  • Return to a loaded tab and notice cached content is reused.

Accessibility notes

  • Panels use semantic fallback content before JavaScript loads.
  • The add-on sets aria-busy and writes polite status messages while loading.
  • Error UI uses role="alert" and a real retry button.
  • This demo mocks fetch locally; it does not call remote services.

Developer notes

  • Imports: A11yTabsLoader from the built add-on module.
  • Panels opt in with data-tab-src.
  • Options used: contentType: "text", custom loading/error text, and callbacks.
  • Use sanitize or renderContent before injecting HTML responses.

The loader owns busy, success, error, retry, and cache state for opted-in panels. Your application must provide a trustworthy endpoint and must sanitize untrusted HTML before inserting it into a panel.

How it works

Each lazy panel declares its source URL in HTML. The loader intercepts activation, exposes loading status, injects the returned HTML, and provides a retry path when the request fails.

HTML

<div data-a11y-tabs>
  <div data-a11y-tabs-list aria-label="Project data">
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="summary">
      Summary
    </button>
  </div>
  <section
    id="summary"
    data-a11y-tabs-panel
    data-tab-src="/api/project-summary"
  ></section>
</div>

JavaScript

import { createTabs } from "../../assets/index.js";
import { A11yTabsLoader } from "../../assets/addons/a11y-tabs-loader.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  const tabs = createTabs(root);
  new A11yTabsLoader(tabs);
}
