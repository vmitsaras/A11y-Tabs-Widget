A11y Tabs Basic Example

The HTML renders readable content before JavaScript runs. The plugin adds ARIA tabs semantics, roving focus, keyboard navigation, and hidden panel state.

Scenario

A shopper compares product details, delivery information, and reviews without losing access to the content when JavaScript is unavailable.

Try it

  • Press Tab to reach the selected tab.
  • Use Arrow keys, Home, and End to move focus.
  • Press Enter or Space to activate the focused tab.
  • Confirm that only the active panel is visible after initialization.

Developer setup

Build the repository first, then serve or open this page. The local source loads from dist; the GitHub Pages mirror rewrites the same live import to docs/assets.

npm install
npm run build
import { createTabs } from "../../assets/index.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  createTabs(root);
}

Keep the tab buttons and panels in the source HTML and give every panel a stable id. createTabs() adds the tab roles, relationships, selection state, and keyboard behavior at runtime; your application remains responsible for meaningful labels and fallback content.

Accessibility behavior

  • Panel content remains readable HTML before JavaScript initializes.
  • The runtime adds tab roles, selected state, panel relationships, and roving tabindex.
  • Real button controls preserve native activation behavior.
  • Final integrations still need testing with target browsers, zoom settings, and assistive technologies.

Implementation limits

  • Provide one tablist and one panel for each tab inside the root.
  • Keep labels, headings, and fallback panel content meaningful.
  • This example uses manual activation and does not enable hash history or optional add-ons.

How it works

Semantic buttons identify their panels by id. The core initializer then adds the ARIA relationships, selection state, roving focus, and keyboard behavior.

HTML

<div class="a11y-tabs" data-a11y-tabs>
  <div data-a11y-tabs-list aria-label="Product information">
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="snippet-details">
      Details
    </button>
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="snippet-shipping">
      Shipping
    </button>
  </div>
  <section id="snippet-details" data-a11y-tabs-panel>...</section>
  <section id="snippet-shipping" data-a11y-tabs-panel hidden>...</section>
</div>

JavaScript

import { createTabs } from "../../assets/index.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  createTabs(root);
}
