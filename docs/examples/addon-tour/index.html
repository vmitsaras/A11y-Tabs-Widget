Creative Studio

Portfolio Onboarding Tour

A creative dashboard guides new collaborators through tabbed project areas with generated, keyboard-accessible tour controls.

Scenario

A producer invites a client to review a project and wants a short, dismissible walkthrough that activates each tab in sequence.

Try it

  • Start the tour and move through each step.
  • Use Escape to skip the tour.
  • Use the tabs directly after the tour to confirm normal behavior remains.

Accessibility notes

  • Generated tour controls are real buttons.
  • The popover uses a group role and clear text for each step.
  • Previous and Next retain focus; the last Next step transfers focus to Finish.
  • Finishing or skipping returns focus to the control that started the tour.
  • Escape skips the tour and removes the active target outline.
  • The tour changes tabs through the public tabs API, so semantic state stays aligned.

Developer notes

  • Imports: A11yTabsTour from the built add-on module.
  • Options used: explicit steps, preferTarget: "panel", and lifecycle callbacks.
  • Set focusOnStep: true only when each step should deliberately move focus to its active tab.
  • Each step can target a panel id, tab id, element, or index.
  • Callbacks update this demo's status region without changing plugin behavior.

Treat the tour as optional guidance, not the only place that explains essential controls. Keep every target stable, provide a clear skip path, and make the underlying tab panels understandable without starting the tour.

How it works

The tour reads the existing panels as ordered stops. Its generated controls activate the corresponding tab while progress and completion messages describe the current position.

HTML

<div data-a11y-tabs>
  <div data-a11y-tabs-list aria-label="Feature tour">
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="welcome">
      Welcome
    </button>
    <button type="button" data-a11y-tabs-tab data-a11y-tabs-panel-id="finish">
      Finish
    </button>
  </div>
  <section id="welcome" data-a11y-tabs-panel>...</section>
  <section id="finish" data-a11y-tabs-panel hidden>...</section>
</div>

JavaScript

import { createTabs } from "../../assets/index.js";
import { A11yTabsTour } from "../../assets/addons/a11y-tabs-tour.js";

const root = document.querySelector("[data-a11y-tabs]");

if (root instanceof HTMLElement) {
  const tabs = createTabs(root);
  new A11yTabsTour(tabs);
}
